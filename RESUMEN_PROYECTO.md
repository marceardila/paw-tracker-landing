## 📞 Soporte Técnico

### Si algo no funciona:

1. **El video/imagen no carga**
   - Verifica que los archivos estén en la misma carpeta
   - Nombres exactos (mayúsculas/minúsculas importan)

2. **Botón de compra no va a Stripe**
   - Verifica el URL del link de Stripe
   - Asegúrate de incluir todo el link

3. **Formulario no envía emails**
   - Por defecto, abre el cliente de email
   - Si quieres envío automático, agregar servicio (Formspree, EmailJS)

4. **Netlify no se actualiza**
   - Espera 2-3 minutos después de hacer push
   - En "Deploys" verás el estado
